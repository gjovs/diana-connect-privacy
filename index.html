Português

Quais dados a extensão coleta

A Diana Connect Helper lida com um único dado: o session token que o widget oficial da Diana (DataSuite Shopee) grava no sessionStorage da página após você concluir o login SSO corporativo. Esse token é uma informação de autenticação vinculada à sua sessão.

Temporariamente, a extensão também guarda no armazenamento local do navegador (chrome.storage.local) os dados da conexão em andamento: endereço da API, identificador da sessão de conexão e identificador público do bot. Esses dados são apagados assim que a conexão é concluída ou após 30 minutos.

Para que serve

O session token é enviado uma única vez, via HTTPS, para a Diana Connect API (infraestrutura interna da Shopee), para concluir a conexão que você mesmo iniciou ao abrir a Connect Page. Sem esse envio, a conexão não acontece.

Compartilhamento

O token é transmitido apenas para servidores da própria Shopee. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para qualquer finalidade fora da conexão descrita acima.

O que a extensão NÃO faz

  • Não coleta histórico de navegação, cookies, conteúdo de páginas ou dados pessoais;
  • Não usa analytics nem telemetria;
  • Não executa em sites fora de datasuite.shopee.io e da Diana Connect API.

Retenção e exclusão

No navegador, os dados temporários são removidos automaticamente ao concluir a conexão. No servidor, o token fica criptografado e associado ao seu usuário até você pedir a remoção ou reconectar. Para excluir, fale com o contato abaixo.

English

What data the extension collects

Diana Connect Helper handles a single piece of data: the session token that the official Diana widget (Shopee DataSuite) stores in the page's sessionStorage after you complete the corporate SSO login. This token is authentication information tied to your session.

It also temporarily stores in the browser's local storage (chrome.storage.local) the in-progress connection details: API address, connection session id, and the bot's public client id. These are deleted once the connection completes or after 30 minutes.

Purpose

The session token is sent once, over HTTPS, to the Diana Connect API (Shopee internal infrastructure) to complete the connection you initiated by opening the Connect Page.

Sharing

The token is transmitted only to Shopee-owned servers. No data is sold, shared with third parties, used for advertising, or used for any purpose unrelated to the connection flow.

What the extension does NOT do

  • It does not collect browsing history, cookies, page content, or personal data;
  • It uses no analytics or telemetry;
  • It does not run on sites outside datasuite.shopee.io and the Diana Connect API.

Retention and deletion

In the browser, temporary data is removed automatically once the connection completes. On the server, the token is stored encrypted and bound to your user until you request deletion or reconnect. To request deletion, contact the address below.
